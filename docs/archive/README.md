# Archive

本目录保存被取代的计划、历史执行流水和仍有追溯价值但不再描述当前项目的材料。

## 规则

- archive 内容只读优先，不作为当前实现、配置、授权或操作说明。
- 移入材料时在文件头写明归档日期、原因和当前替代文档。
- 当前文档链接历史材料时，应明确说明其历史性质。
- 不为了保持历史“看起来正确”而用新政策改写旧证据。
- 没有追溯价值的临时文件应删除，而不是把 archive 当作垃圾桶。

建议文件头：

```text
Archived: YYYY-MM-DD
Reason: superseded / completed ledger / historical reference
Current owner: ../path/to/current-document.md
```
